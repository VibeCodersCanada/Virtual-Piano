# 🎹 Virtual Piano (Web Audio Synth)

A fully interactive virtual piano built using vanilla JavaScript and the Web Audio API.  
It supports multiple instruments, real-time synthesis, recording, playback, and a live audio visualizer.

---

## 🚀 Features

- 🎹 Playable on-screen piano (mouse + keyboard)
- ⌨️ Keyboard mapping (A–L keys + sharps)
- 🎼 Multiple instruments:
  - Piano (triangle harmonic model)
  - Organ (multi-oscillator)
  - Synth (saw + filter sweep)
  - Bell (FM-style harmonics)
- 🎚 Volume control
- 🌊 Reverb effect (custom impulse response)
- 📊 Live waveform visualizer
- ⏺ Recording system
- ▶ Playback of recorded notes
- 🎼 Multi-octave support (3–5)

---

## 🧠 Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Web Audio API

### Extra Controls
- `Z` → Lower octave  
- `X` → Raise octave  
- Mouse click → Play note  
- Record button → Start/stop recording  
- Play button → Playback recording
